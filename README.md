# 🎬 FlowMusic 导演台 (社区体验版)

> 一款面向视频与短剧创作者的本地 AI 配乐辅助工具。用日常大白话描述想要的画面感觉，即可生成配乐方案并自动同步保存至本地音乐文件夹。

## 🚀 30 秒快速上手

### 1. 环境要求
- Windows 10 / 11 系统
- 已安装 [Node.js](https://nodejs.org/)（建议 v18 或更高版本）与 Chrome / Edge 浏览器

### 2. 加载浏览器桥接插件（仅首次需要）
1. 打开 Chrome 或 Edge 浏览器，在地址栏输入 `chrome://extensions/`（或 `edge://extensions/`）并回车。
2. 打开右上角的 **「开发者模式」** 开关。
3. 点击左上角 **「加载已解压的扩展程序」**，选择本项目文件夹内的 **`chrome-extension`** 目录。

### 3. 启动程序
- 双击运行 **`FlowMusic导演台.exe`** 或 **`启动FlowMusic导演台.bat`**。
- 浏览器会自动打开操作台界面，输入你想要的画面氛围即可开始体验。
